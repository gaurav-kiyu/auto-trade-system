# 00-REPOSITORY-TRUTH-INTEGRITY.md

## SOURCE-OF-TRUTH RULE

The actual repository, executable behavior, and empirical test evidence
are authoritative.

Documentation, previous audit reports, previous agent conclusions,
previous "PASS" statuses, and previous certification reports are NOT
authoritative if contradicted by current evidence.

If:

CODE ≠ DOCUMENTATION
TEST ≠ DOCUMENTATION
SCREEN ≠ TEST
EVIDENCE ≠ CERTIFICATION

the status MUST be:

CONTRADICTED

and completion is prohibited until reconciled.
