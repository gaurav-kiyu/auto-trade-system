RealEstate India API

Complete REST API reference — 45+ endpoints for property management, CRM, auctions, and platform operations.

🏠 Properties

POST /api/realestate/properties

Create a new property listing. All fields are query parameters.
ParameterTypeReqDescription
titlestring✓Property title (max 100 chars)
pricefloat✓Price in INR (min ₹1,000)
citystring✓City name
property_typeenum—apartment, house, villa, penthouse, studio
bedroomsint—Number of bedrooms
localitystring—Locality/area name
# Create a 2BHK in Bandra
curl -X POST "/api/realestate/properties?title=Modern%202BHK%20in%20Bandra&price=25000000&city=Mumbai&property_type=apartment&bedrooms=2"

GET /api/realestate/properties

Search properties with multi-criteria filtering, pagination, and sorting.
ParameterTypeDefaultDescription
citystring—City filter
min_pricefloat0Minimum price
max_pricefloat1BMaximum price
property_typeenum—apartment, villa, house, etc.
furnishingstring—furnished, semi_furnished, unfurnished
pageint1Page number
page_sizeint20Items per page (max 100)
# Search 3BHK in Bangalore under 2 crore
curl "/api/realestate/properties?city=Bangalore&min_bedrooms=3&max_price=20000000"

GET /api/realestate/properties/{property_id}

Get detailed information about a specific property.
# Get property details
curl "/api/realestate/properties/RE-20260726-ABCD12"

DELETE /api/realestate/properties/{property_id}

Delete a property listing.

🔍 Search & Filters

GET /api/realestate/properties

The main search endpoint supports 14 filter criteria including: query, city, locality, property_type, listing_type, min/max price, min/max bedrooms, furnishing status, amenities, verified_only, with_virtual_tour, and sort options (price, area, views, listed_at). Results include facet counts for cities and property types.
# Advanced search with sorting and facets
curl "/api/realestate/properties?city=Pune&property_type=villa&sort_by=price&sort_order=asc&page_size=10"

🎯 Recommendations

GET /api/realestate/recommendations

Get AI-powered property recommendations. Optionally pass a property_id to get similar properties in the same city/price range.
# Get 6 similar properties
curl "/api/realestate/recommendations?property_id=RE-001&limit=6"

🗺️ Map Data

GET /api/realestate/map-data

Get property coordinates for map visualization. Returns properties with valid latitude/longitude, optionally filtered by city.
# Get all Mumbai properties for map
curl "/api/realestate/map-data?city=Mumbai"

👥 Lead Management (CRM)

POST /api/realestate/leads

Create a new sales lead from buyer information.

GET /api/realestate/leads

List all leads, optionally filtered by status.

PUT /api/realestate/leads/{lead_id}/status

Update lead status through pipeline stages: new → contacted → interested → visit_scheduled → visit_completed → negotiating → closed/lost.

📩 Enquiries

POST /api/realestate/enquiries

Submit a property enquiry from a buyer/tenant/broker.

GET /api/realestate/enquiries

Get enquiries, optionally filtered by property.

📝 Rent Agreements

POST /api/realestate/agreements/rent

Create a rent agreement with e-stamping and e-sign support. Includes notice period, lock-in, and security deposit (max 12× rent).

GET /api/realestate/agreements/rent/{agreement_id}

Get agreement details with e-stamp and e-sign status.

POST /api/realestate/agreements/rent/{agreement_id}/e-stamp

Initiate e-stamping via SHCIL. Generates e-stamp paper number.

POST /api/realestate/agreements/rent/{agreement_id}/e-sign

Initiate Aadhaar e-sign for landlord, tenant, or both parties.
# Sign on behalf of both landlord and tenant
curl -X POST "/api/realestate/agreements/rent/AG-001/e-sign?party=both"

💳 Rent Payments

POST /api/realestate/tenant/payments

Record a rent payment made via UPI, NEFT, card, cash, or cheque.

GET /api/realestate/tenant/payments

Get payment history and outstanding balance for a tenant.

🔧 Maintenance

POST /api/realestate/tenant/maintenance

Submit a maintenance request (plumbing, electrical, emergency, etc.).

GET /api/realestate/tenant/maintenance

List maintenance requests with status tracking.

PUT /api/realestate/tenant/maintenance/{req_id}/status

Update request status: submitted → acknowledged → in_progress → resolved.

🤖 AI Chatbot

POST /api/realestate/chat

Ask questions about properties, legal FAQs (RERA, documents, loans), rent agreements, and neighborhoods. Uses intent classification + keyword matching + SequenceMatcher on 11 FAQ entries.
# Ask about RERA
curl -X POST "/api/realestate/chat?message=What%20is%20RERA%3F"

⚙️ Platform

GET /api/realestate/health

Health check endpoint — returns status and timestamp.

GET /api/realestate/languages

List supported languages (10 Indian languages: Hindi, Marathi, Tamil, Telugu, Bengali, Gujarati, Kannada, Malayalam, Punjabi).

GET /api/realestate/neighborhood/cities

List all 10 supported cities with locality data, average prices, and quality ratings (schools, hospitals, connectivity, safety, AQI).
