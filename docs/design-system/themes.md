# Theme Architecture

The OPB platform provides 9 production themes:

1. **🌌 Dark Cyber (`dark-cyber`)**: Default institutional quant cockpit with high-tech blue accents.
2. **❄️ Nordic Frost (`nordic-frost`)**: High-contrast Scandinavian day-trading light theme.
3. **🏛️ Ivory & Gold (`ivory-gold`)**: Luxury warm daylight wealth-management theme.
4. **👑 Obsidian Gold (`obsidian-gold`)**: Ultra-luxury dark gold VIP quant tier.
5. **☀️ Sapphire Day (`midnight-slate`)**: Modern finance light theme with sapphire blue and cool neutral surfaces.
6. **🟩 Emerald Matrix (`emerald-matrix`)**: Terminal quant theme with high-visibility market green accents.
7. **🌸 Plum Cloud (`dracula-purple`)**: Premium light theme with plum-violet and rose accents.
8. **🗼 Tokyo Night (`tokyo-night`)**: Neon noir aesthetic with clean indigo typography.
9. **🐱 Catppuccin Mocha (`catppuccin-mocha`)**: Refined pastel dark palette with soft contrast curves.
