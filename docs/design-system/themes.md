# Theme Architecture

The OPB platform provides 5 canonical production themes:

1. **🌌 Dark Cyber (`dark-cyber`)**: Default institutional quant cockpit with high-tech blue accents (Dark).
2. **🌸 Plum Cloud (`dracula-purple`)**: Premium light theme with plum-violet and rose accents (Light).
3. **🏛️ Ivory & Gold (`ivory-gold`)**: Luxury warm daylight wealth-management theme (Light).
4. **☀️ Sapphire Day (`midnight-slate`)**: Modern finance light theme with sapphire blue and cool neutral surfaces (Light).
5. **❇️ Emerald (`emerald-matrix`)**: Terminal quant theme with high-visibility market green accents (Dark).
