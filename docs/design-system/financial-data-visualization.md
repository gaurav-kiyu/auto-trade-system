# Financial Data Visualization

## Candlestick & Technical Standards
- **Green Candle (Bullish)**: `--chart-candle-up` (`#16a34a` / `#22c55e`)
- **Red Candle (Bearish)**: `--chart-candle-down` (`#dc2626` / `#ef4444`)
- **VWAP Line**: `#eab308` (Gold)
- **9 EMA**: `#38bdf8` (Sky Blue)
- **21 EMA**: `#a855f7` (Purple)
