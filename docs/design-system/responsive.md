# Responsive Breakpoints

- **Desktop Ultrawide**: 1440px+
- **Desktop Standard**: 1280px - 1439px
- **Laptop / Compact**: 1024px - 1279px
- **Tablet / Mobile Shell**: 768px - 1023px
- **Mobile PWA**: 320px - 767px

## Shell Contract

The canonical mobile app bar, navigation drawer, and bottom navigation dock activate below **1024px**.
The page-content layout may use narrower breakpoints inside individual screens, but the global shell breakpoint is 1024px.
