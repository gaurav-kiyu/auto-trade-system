# Accessibility (WCAG 2.1 AA)

- **Color Contrast**: 4.5:1 minimum contrast ratio for standard text; 3:1 for large display headers and active UI boundaries.
- **Focus Rings**: `box-shadow: 0 0 0 3px rgba(56, 189, 248, 0.25)` on keyboard navigation.
- **Form Labels & ARIA**: Mandatory `aria-label` or visible `<label>` tags on all inputs and interactive triggers.
