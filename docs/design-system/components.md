# Component Library

## Core Abstractions
- **`.opb-card`**: Standard elevated container with dynamic border and card shadow.
- **`.opb-stat-card`**: Metric card with hover elevation (`translateY(-2px)`).
- **`.opb-table`**: High-contrast data table with sticky headers and tabular numerals.
- **`.opb-badge`**: Rounded status pill for Buy, Sell, Neutral, and Warning states.
- **`.opb-tab-bar` & `.opb-tab`**: Segmented control pill navigation dock.
- **`.opb-input` & `.opb-select`**: Form controls with focus glow rings.
