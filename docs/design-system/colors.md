# Semantic Color Palette

## Market Semantics (Indian Market Standard)
- **BUY / ACCUMULATE / PROFIT**: `--market-buy` (`#16a34a` in light, `#22c55e` in dark)
- **SELL / SHORT / LOSS**: `--market-sell` (`#dc2626` in light, `#ef4444` in dark)
- **NEUTRAL / ACCENT**: `--market-neutral` (`#0284c7` in light, `#38bdf8` in dark)
- **WARNING / EXPIRY RISK**: `--market-warning` (`#d97706` in light, `#f59e0b` in dark)

No component should use hardcoded hex codes. All colors must resolve through dynamic CSS variables.
